# LiPo Battery Monitor (v1.0)

デバイスから回収した2600mAh LiPoバッテリーを監視するシステム。

## 仕様
- **Reference Voltage:** Arduinoの内部基準電圧(1.1V)を使用。これによりバッテリー電圧低下時の測定誤差を排除。
- **Voltage Divider:** 10kΩ/2.2kΩ (約1/5.5倍) で分圧し、1.1V以下で受ける構成。
- **Display:** LCD1602 (16ピン直接制御)。

## Hardware Design
回路図はKiCadで作成しました。分圧回路で1.1V以下に抑えています。

## ハマった点
- ブレッドボードの中央ライン断絶によるGND浮き。
- 電源電圧と基準電圧が同期していると、自身の電圧低下を測れない問題。
